# v4 新功能

顶部新增“主题外观”“背景音乐”“AI 分析”入口。

- 主题：多套整站外观；选择自动保存在当前浏览器，同步图表、大屏与视频背景。
- 网页音乐：系统内置 29 首来自指定 Music 目录的曲目，不需要选择或授权文件夹。首次点击页面后随机播放，可暂停、换曲、调音量；浏览器不允许无交互强制自动播放。
- 视频音乐：在视频工作室“视频背景音乐”选择内置曲目、无背景音乐或上传自定义音频。网页当前播放曲目不影响导出。默认无音乐；短曲自动循环，末尾裁切。独立模块静音。
- 内置曲目转为 AAC/M4A，直接复制、解压即可使用。music/*.js 是直接打开本地 HTML 时的音频加载副本，不要删除；HTTP 部署使用 M4A。
- AI 分析：自行配置 OpenAI 兼容 API 地址、模型、密钥和系统提示词，也可调用自己的 HTTP Agent 服务。不会自动调用本机命令行 Agent。请求由浏览器直接发送，目标服务必须允许当前网页的 CORS。默认不发送表格，勾选后才附带当前数据。
- API 设置可保留在本机，密钥不写入导出包或数据备份。未提供真实 API 凭据，因此真实付费服务的连通性需配置后验证。

音乐来自用户提供的本地目录；使用或公开分发生成视频前，请自行确认相关音乐授权。

启动本地版：完整解压后双击 Windows.bat，或直接打开 index.html。源码位于 web/；服务器版源码位于 vps/。
